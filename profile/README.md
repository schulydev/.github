Schuly is an independent app for students at schools in Switzerland. Grades, exams, timetable, absences and documents, in one place.

> Schuly is **NOT** affiliated with, endorsed by, or connected to Schulnetz or Centerboard AG.

**Use it:** [Schuly](https://github.com/schulydev/Schuly) is the app, with downloads in its [releases](https://github.com/schulydev/Schuly/releases). [SchulyWebsite](https://github.com/schulydev/SchulyWebsite) is the landing page.

**Run it:** [SchulyServer](https://github.com/schulydev/SchulyServer) is the API and web app, and [SchulyMicrosoft](https://github.com/schulydev/SchulyMicrosoft) adds Microsoft 365.

**Extend it:** [SchulyPluginAbstractions](https://github.com/schulydev/SchulyPluginAbstractions) is the plugin contract, and [SchulyPlugins](https://github.com/schulydev/SchulyPlugins) has the plugins built on it.

**Read about it:** [SchulyDocs](https://github.com/schulydev/SchulyDocs) is the source of the docs.

Apps and services use PolyForm Noncommercial 1.0.0. Plugins and the plugin contract use MIT.
